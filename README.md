## Built with

| Tool | How it is used |
| --- | --- |
| **HTML5** | Semantic single-page structure: nav, hero, events, explore, tours, about, contact, chat |
| **CSS3** | Design tokens, editorial type, magazine grids, carousel, and responsive layouts |
| **JavaScript** | Mobile navigation, scroll-aware nav, back-to-top, and the Amara concierge chat |
| **Google Fonts** | [Cormorant Garamond](https://fonts.google.com/specimen/Cormorant+Garamond) for headlines, [Source Sans 3](https://fonts.google.com/specimen/Source+Sans+3) for UI |
| **CSS custom properties** | Cream, sand, ink, and terracotta palette shared across the page |

## On the page

- **Home** — Full-bleed hero, Tourismania wordmark, and an invitation into the journal
- **Upcoming events** — Everest camp trek, walking holidays, and Andaman Beaches
- **Explore the world** — Flaubert’s line, set over travel photography
- **Tours & destinations** — Port of Spain (28 Jan 2026), Gasparee Caves (14 Mar 2026), Trinidad North Coast (5 May 2026)
- **About** — Photograph carousel and the Tourismania story
- **Why Tourismania** — Guided trips, small groups, destinations
- **Contact** — Message form and [tourismania@gmail.com](mailto:tourismania@gmail.com)
- **Chat** — Amara, Tourismania Official — open from the nav or the contact desk
